# Hi, I'm Devansh Palan 👋

**Software engineer who builds AI agents and full-stack products end to end.**

I'm a B.Tech student and former research intern at **IVLabs** (deep reinforcement learning), now focused on building production-grade agentic systems — code-understanding agents, AI-triaged workflows, and automation services that ship with tests, Docker, and CI-ready structure.

## 🔭 What I'm building

- 🤖 [**RepoBot**](https://github.com/devansh-palan/RepoBot) — a codebase Q&A + PR-review agent: indexes repositories with tree-sitter, grounds every answer in retrieved code, and self-checks its responses before replying
- 💰 [**HisaabPakka**](https://github.com/devansh-palan/HisaabPakka) — a finance-controller agent where *AI proposes, arithmetic disposes*: LLM reasoning gated by deterministic reconciliation checks
- ⚙️ [**Automation**](https://github.com/devansh-palan/Automation) — production Node.js + TypeScript service automating government self-service portals with Playwright, fully Dockerized with Jest test suites

## 🧰 Other work I'm proud of

- 🏠 [**Hostel Grievance Management System**](https://github.com/devansh-palan/Hostel-Grievance-Management-System) — full-stack complaint portal with Gemini-powered priority triage, Cloudinary uploads, and email/SMS alerts
- ⚡ [**ZapCompare**](https://github.com/devansh-palan/ZapCompare) — grocery price comparison across Blinkit, Instamart & Zepto with Redis caching and JWT auth
- 🗣️ [**VoiceCloning**](https://github.com/devansh-palan/VoiceCloning) — three-stage neural voice cloning pipeline (speaker encoder → Tacotron → WaveRNN vocoder)
- 🕹️ [**Deep RL @ IVLabs**](https://github.com/devansh-palan/Summer-Intern-at-IVLabs-2024-Deep-Reinforcement-Learning) — DP → tabular RL → PPO/DQN agents trained across FrozenLake, MiniGrid, and ViZDoom
